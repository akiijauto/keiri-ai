# freee CSV仕様の確認メモ

## 必ず確認すること（実装確定前）

freeeのCSVインポート仕様はバージョンで変わるため、
以下をfreee公式ヘルプで確認し、`api/freee_csv.py` の `COLUMNS` に反映すること。

| 確認項目 | 現在の実装値 | 確認状況 |
|---|---|---|
| インポート種別 | 振替伝票形式を想定 | 未確認 |
| 列名と順序 | 日付/借方勘定科目/借方金額/借方税区分/貸方勘定科目/貸方金額/貸方税区分/備考/取引先 | 未確認 |
| 文字コード | cp932 (Shift_JIS) | 未確認 |
| 日付形式 | YYYY/MM/DD | 未確認 |
| 改行コード | CRLF | 未確認 |
| 税区分の表記 | 「課対仕入10%」等 | 未確認 |
| ヘッダー行の要否 | あり | 未確認 |

## 差分が出た場合の対応

`api/freee_csv.py` の以下3箇所だけ直せば吸収できる設計にしてある。

- `COLUMNS` … 列名と順序
- `ENCODING` … 文字コード
- `DATE_FORMAT` … 日付形式
- `JournalRow.to_row()` … 値の並び

## 補足

- 勘定科目名はfreeeの事業所ごとにカスタマイズ可能。
  受託案件では必ず先方の科目一覧を取得し `api/accounts.py` を差し替えること。
- 税区分もfreeeの表記に完全一致していないとインポートエラーになる。
