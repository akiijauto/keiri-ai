Secure Local OCR — Web連携デモ

完全オンデバイスOCR入力支援システム ／ SLO Handoff Protocol v1.0

この画面について

本システムは、個人情報を含む紙資料を端末内だけでOCRし、 人間が確認した項目だけを業務Webサイトへ入力する仕組みです。 OCR対象の画像・OCR結果は、クラウドOCRにも生成AIにも送りません。

このデモサーバは 127.0.0.1 にのみバインドされ、 CSPで外部への通信をすべて禁止しています。表示されているデータはすべて架空です。

2つの取込元、1つの受け口

取込元が Android/iOS の OCR アプリでも、Webの入居フォームでも、 登録先へ渡すデータの形式・正規化規則・検証手順は共通です。 登録先は受け口を1つ実装するだけで両方に対応できます。

  • 取込元A：OCRアプリ（Android / iOS）— 撮影 → 端末内OCR → 項目抽出 → 人間の確認 → 引き渡し
  • 取込元B：入居フォーム（Web）— 直接入力 → 同じ正規化 → 人間の確認 → 引き渡し
  • 登録先：業務Webサイト — 検証 → 入力欄へ充填 → 人間が送信

試す

入居フォーム（取込元B）を開く
入力すると、登録先の画面が開いて自動で充填されます。送信は人間が押します。

登録先の申込フォームを直接開く
OCRアプリのWebViewから開かれる想定の画面です。単体で開くと取込元が見つからない状態になります。
