タブレット実機確認の手順

Secure Local OCR ／ Androidタブレット単体で実施できる範囲 ／ 版 0.1
README 要件定義 振り返り テスト計画 セキュリティ設計

この手順でできること

Androidタブレットが1台あれば、PCも通信監視機材も無しに MVPの未検証項目の大半を確認できます。

確認できること必要なもの
日本語帳票のOCR精度タブレットと印刷した検証用紙のみ
処理速度（撮影から結果表示まで）同上
ネットワーク無しで完走できること同上（機内モードにする）
OCR中に通信していないこと同上（下記のとおり権限で確認）
誤認識の修正と確認の操作性同上
画像・データが端末に残らないこと同上
Webフォームへの充填（Level 3/4）別途、同じWi-Fi上のPCが必要（§6）

1. 準備

1-1. 検証用紙を用意する

secure-local-ocr/samples/ にサンプルがあります。 印刷できる場合はPDF、できない場合は画面表示用のPNGを使ってください。

状況使うファイルやり方
印刷できるtest-form-01.pdf / test-form-02.pdf A4で印刷して撮影。実際の運用に近い条件
印刷できないtest-screen-01.png（縦）/ test-screen-02.png（横） スマホやPCの画面に全画面表示し、タブレットで撮影。 画面の明るさは最大にし、部屋の照明の映り込みを避ける
画面撮影は紙より条件が悪くなります。 バックライトとモアレで輪郭が甘くなるためです。 画面で読めれば紙でも読めますが、逆は成り立ちません。 画面撮影の結果は「下限の目安」として記録し、印刷できる環境ができたら取り直してください。
ファイル内容
test-form-01.pdf入居申込書。必須6項目を含む標準的な様式
test-form-02.pdf連絡先登録票。ラベルの次の行に値がある様式と、小さい文字
test-screen-01.png入居申込書（画面表示用・縦）。文字を大きくしたもの
test-screen-02.png連絡先登録票（画面表示用・横）
expected-values.html期待値の一覧（答え合わせ用）。用紙には載せていません
用紙に印字されているのはすべて架空データです。 実在の個人情報を印刷して検証しないでください。

1-2. 端末の前提を満たす

  • Android 8.0（API 26）以上
  • 画面ロック（PIN・パターン・生体認証）が設定されていること。 未設定の端末では、設計上アプリを開始できません
  • Root化されていないこと（検出されると開始できません）

2. インストール

  1. タブレットのブラウザでGitHubにログインする（リポジトリは非公開のため必要）
  2. リポジトリの Releases を開き、最新の「Secure Local OCR 実機検証ビルド」を選ぶ
  3. SecureLocalOCR-offline-arm64-v8a-*.apk をタップしてダウンロードする
  4. ダウンロード通知をタップしてインストールする。 「不明なアプリのインストール」を求められたら、そのブラウザに対して許可する
APKINTERNET権限使いどころ
offline-arm64-v8a持たない まずこちら。撮影・OCR・抽出・確認まで。引き渡しは表示とコピー
offline-universal持たない 上記が入らない端末向けの控え。サイズが倍になる
web-arm64-v8a持つ（許可リスト限定） Webフォームへの充填まで確認する場合（§6）

APKはCPUの種類（ABI）ごとに分けて配布しています。同梱している日本語OCRモデルと ネイティブライブラリが全ABI分入ると50MBを超え、配布経路によっては扱えないためです。 現行のタブレットはほぼ arm64-v8a です。 「アプリがインストールされていません」と出る場合は universal を試してください。

どちらもデバッグ署名のビルドです。動作確認専用で、業務端末への正式配布には使えません。 両方を入れても、パッケージ名が違うので共存します。

3. まず確認してほしいこと：通信権限が無いこと

このシステムの根拠にあたる部分なので、最初に確認してください。 アプリを起動して認証する前に確認できます。

方法A：アプリの画面で見る

  1. アプリを起動する（認証はまだしない）
  2. 「ビルド情報と検証設定」をタップする
  3. 先頭に 「このビルドは通信権限を持っていません」 と表示されることを確認する

方法B：Androidの設定で見る（アプリの自己申告に頼らない確認）

  1. 端末の「設定」→「アプリ」→「Secure Local OCR」を開く
  2. 権限の一覧に カメラだけが並び、通信に関する項目が無いことを確認する
offlineビルドは INTERNET 権限を宣言していません。 Androidはこの権限が無いアプリにソケットを開かせないため、 OCR中に外部へ送信することが、実装の善し悪しと無関係に起こり得ません。 通信監視の機材が無くても、この一点は端末上で確認できます。

4. 機能の確認（20〜30分）

4-1. 機内モードで完走できるか（最重要）

  1. タブレットを機内モードにする
  2. アプリを起動して認証する
  3. 検証用紙 test-form-01 を枠内に収めて「撮影してOCR」
  4. 確認画面まで到達することを確認する

合格条件：機内モードのまま、撮影から確認画面まで完了できること。

4-2. 読み取り精度

確認画面の各項目を samples/expected-values.html と突き合わせて、 ○（そのまま使える）／△（軽微な修正）／×（読めない・誤り）を記録してください。

#条件やること
1明るい場所・正対基準となる精度を見る
215度ほど傾ける必須項目が取れるか
330度ほど傾けるここは「要確認」扱いでも可
4薄暗い場所誤った値を確定させないか
5光の反射がある状態同上
6test-form-02（次行に値・小さい文字）ラベル次行の抽出と、小さい文字の扱い
見てほしいのは「読めたかどうか」だけではありません。 読めなかったときに、もっともらしい誤った値を確定できてしまわないかが重要です。 読めない場合は「要修正」と表示されるのが正しい挙動です。

4-3. 速度

撮影ボタンを押してから確認画面が出るまでを数回計測してください。 確認画面の上部に「認識 ○行 / ○○ms」と出ます。この数値を記録してください。 目標は3秒以内ですが、初回はモデルの読み込みで遅くなることがあります。

4-4. 修正と確認の操作

  1. 誤認識された項目を手で直す → その場で再検証され、エラー表示が消えることを確認
  2. 各項目の「この内容で確認しました」にチェックを付ける
  3. 必須項目が揃うまで「Web入力へ進む」が押せないことを確認

5. セキュリティの確認（10分）

#確認すること手順合格条件
S-1画像が保存されない撮影後、ギャラリー／フォトを開く撮影した書類が存在しない
S-2スクリーンショット抑止確認画面でスクリーンショットを試す 撮影できない（許可設定を入れていない場合）
S-3タスク切替時の秘匿アプリ切替画面を開く画面の内容が見えない
S-4再認証確認画面のまま3分以上放置して戻る値が破棄され、認証からやり直しになる
S-5終了後に残らない「終了して破棄」→アプリを終了→再起動前回の値が復元されない
S-6監査ログに値が無い「ビルド情報と検証設定」の監査ログ欄を見る イベント名と件数だけで、氏名・番号が無い
S-2 が「撮影できない」ため、結果を画面で記録できません。 記録が必要な場合は「ビルド情報と検証設定」で 「スクリーンショットを許可」を一時的にオンにしてください （デバッグビルドのみ・架空データでの検証時に限る）。 切り替えるとアプリが作り直されます。確認が終わったらオフに戻してください。

6. Webフォームへの充填を確認する場合（PCが必要）

ここだけはタブレット単体では確認できません。登録先のWebサイトが必要なためです。 同じWi-Fiに繋がるPCがあれば、参照実装を動かして確認できます。

  1. PCでリポジトリを取得し、参照実装を起動する 
    cd secure-local-ocr/web
node server.mjs

    既定では 127.0.0.1 にのみバインドしているため、そのままではタブレットから繋がりません。 検証時に限り、PCのLAN内アドレスで待ち受けるようにしてください（起動時の引数で変更できます）。

  2. PCのIPアドレスを調べる（例: 192.168.1.10）
  3. タブレットに SecureLocalOCR-web-*.apk を入れる
  4. アプリの「ビルド情報と検証設定」で登録先URLを http://192.168.1.10:8787/registration/ に変更して保存する
  5. 撮影 → 確認 → 「Web入力へ進む」→「この内容を入力する」

合格条件：入力欄が埋まること。そして自動送信されないこと。

登録先URLを端末上で変更できるのはデバッグビルドだけです。 リリースビルドでは組み込みの許可リスト以外のオリジンへ値を渡しません。

8. うまくいかないとき

症状原因と対処
「認証して開始」が押せない 端末に画面ロックが未設定。設定してから再起動する
「この端末は業務利用できません」と出る Root化またはカスタムビルドと判定された。別の端末で試す
インストールできない ブラウザに「不明なアプリのインストール」を許可する。 古い版が入っている場合は先にアンインストールする
カメラが真っ暗 カメラ権限を許可する。他のアプリがカメラを掴んでいたら閉じる
文字が認識されない 枠内に収める。明るさと角度を変える。用紙を平らにする
初回だけ極端に遅い モデルの読み込み。2回目以降の値で判断する
「Web入力へ進む」が押せない 必須項目の確認チェックが揃っていない。警告に出ている項目を埋める
